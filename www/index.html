Homing

          
Homing moves the machine toward endstops.

          
Run M119 before homing if you are unsure about endstop state.

          
If endstops show TRIGGERED when they are not pressed, do not home.

          

            
            
            
            
          

        


        

          
Jog / Virtual Joystick

          
Safe Jog moves Z to the safe target before XY movement by default.

          
After XY jog stops, firmware restores the previous Z after about 5 seconds if Z was not changed.

          
Software stop is not a physical emergency stop.
